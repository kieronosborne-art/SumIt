Designed for real maths and science workflows

Type or paste — with smart autocomplete

The Editor is built on MathLive. Type LaTeX, use keyboard shortcuts, or paste from Word. Type the first three letters of a named formula and SumIt suggests it — from "sq" for square root to "schrod" for the Schrödinger equation.

300+ named formulas, filtered by level and subject

Algebra, trig, calculus, statistics, mechanics, electromagnetism, thermodynamics, optics, chemistry — all searchable, all with rendered previews. Filter by age (≤16, 16–18, University) or by syllabus (GCSE, A-Level, IB) so pupils only see what's relevant to them.

Draw equations by hand — recognised on-device

Sketch with a finger, stylus or trackpad. Two recognisers ship with SumIt: a fast template matcher for everyday symbols, and a neural-network model for messier handwriting. Both run entirely on your device.

Graph and sonify functions

Plot up to six functions simultaneously in Cartesian, polar or parametric form. Audio-trace any curve to hear the shape — useful for teaching, and essential for visually-impaired pupils.

Render chemistry too

Type ordinary chemistry shorthand (H2SO4 + 2NaOH -> Na2SO4 + 2H2O) and SumIt renders proper subscripts, charges, and balanced equations via the mhchem package.

Built on Universal Design for Learning principles

SumIt makes maths and science notation more accessible by removing many of the barriers associated with traditional pen-and-paper methods. With a range of flexible input options, users can create and work with notation in the way that suits them best — opening up greater access to academic study and the workplace.
